# Stock-Market-Help
Actively monitors live data for over 2,600 Indian stocks in real-time. It fetches prices and queue alerts in the background without ever freezing the visual interface. By tapping directly into your operating system's native text-to-speech engine, it verbally announces scheduled price updates and instant alerts for major portfolio drops or gains.

Open VS Code, Enter the unzipped folder into VS Code and open the terminal then into the terminal paste: 
"python -m venv venv"
".\venv\Scripts\activate"

To use this, you need to get some libraries: So paste the following in your terminal: "pip install yfinance pandas requests"

then, Paste into the terminal "python main.py"

Wait for a few seconds, it is slightly heavy. Also, i have pasted all this because I am nervous about adding an .env file
